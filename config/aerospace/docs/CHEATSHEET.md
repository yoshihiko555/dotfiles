# AeroSpace チートシート

アプリの配置先と普段のキー操作をまとめた。配置ルールの変更、新しい Mac や BetterTouchTool（BTT）の設定は [AeroSpace の README](../README.md) を参照。

## ワークスペースの切り替え

| キー | WS | モニター | アプリ |
|---|---|---|---|
| `ctrl-1` | M1 | メインDELL | Google Chrome |
| `ctrl-2` | M2 | メインDELL | Dia |
| `ctrl-3` | M3 | メインDELL | Ghostty（常用）/ WezTerm（サブ） |
| `ctrl-9` | M4 | メインDELL | （空き枠。Hermes の画面共有等） |
| `ctrl-4` | S1 | サブDELL | Notion |
| `ctrl-5` | S2 | サブDELL | Zed / VS Code / TablePro |
| `ctrl-6` | S3 | サブDELL | Finder |
| `ctrl-0` | S4 | サブDELL | システム設定 / Activity Monitor / CotEditor |
| `ctrl-7` | B1 | Mac本体 | Slack / Discord / Teams |
| `ctrl-8` | B2 | Mac本体 | Mail / Notion Calendar |
| `ctrl-shift-1` | B3 | Mac本体 | OrbStack |

空き枠の M4 は手動で使う。配置ルールのないアプリは開いたワークスペースに留まる。

## キーとスワイプ

| 操作 | キー・ジェスチャ | 動作 |
|---|---|---|
| 同じモニター内で次へ | `ctrl-→` または 3 本指で左にスワイプ（BTT） | M1〜M4、S1〜S4、B1〜B3 の各グループ内で、末尾から先頭へ戻る |
| 同じモニター内で前へ | `ctrl-←` または 3 本指で右にスワイプ（BTT） | 逆順に巡回する |
| ウィンドウを別のワークスペースへ送る | `ctrl-cmd-数字` | 移動先は上の表の数字と同じ。フォーカスは元の画面に残る。B3 への移動キーは未設定 |
| 左のモニターへ移動 | `shift-alt-←` | ウィンドウとフォーカスが一緒に移る。左端からは右端に回る |
| 右のモニターへ移動 | `shift-alt-→` | ウィンドウとフォーカスが一緒に移る。右端からは左端に回る |
| 一時的に全域へ広げる | `alt-↑` | 全画面表示を切り替える。同じワークスペース内の別ウィンドウにフォーカスを移すと解除される |
| 分割方式を切り替える | `ctrl-alt-a` | tiles と accordion を切り替える。accordion は非アクティブなウィンドウを端に畳み、フォーカスしたものを広く表示する |

## ウィンドウの自動整列

新しいタイル型ウィンドウを開くと、アプリの種類を問わず、配置先のワークスペースで次のように並ぶ。フローティングウィンドウは枚数に含めない。

| 枚数 | 配置 |
|---|---|
| 1 | 通常どおり |
| 2 | 左右に半分ずつ |
| 3 | 左に 1 枚、右に上下 2 枚 |
| 4 | 2×2 の均等な配置 |
| 5 以上 | 自動整列せず、通常の AeroSpace の配置に任せる |

2〜4 枚の整列時には手動の分割比率や accordion もタイル配置に戻る。並びはウィンドウ ID の昇順で、4 枚なら左上・左下・右上・右下の順。フォーカスは移動しない。ウィンドウを閉じたときや別のワークスペースへ送ったときは、AeroSpace 標準の配置になる。
