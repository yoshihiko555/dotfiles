# lazygit チートシート

起動は `lg`（`alias lg='lazygit'`）。UI は `gui.language: ja` で日本語化済み。
**迷ったら `?`** — 今フォーカスしているパネルで押せるキーが全部出る。

対象バージョン: lazygit 0.64.1（キーはすべてデフォルト設定の実測値）

---

## 1. まず覚える 5 つ

| キー | 動作 |
|------|------|
| `?` | 今のパネルのキー一覧を表示（最重要） |
| `Esc` | 一段戻る / メニューを閉じる |
| `q` | lazygit を終了 |
| `1`〜`5` | パネルへ直接ジャンプ |
| `+` | パネルを拡大（もう一度で全画面）、`_` で戻す |

## 2. 画面の構成

左側に 5 つのパネル、右側（`0`）に選択中の項目の内容が出る。

| 番号 | パネル | 何が見えるか |
|------|--------|--------------|
| `1` | ステータス | 現在のリポジトリとブランチ |
| `2` | ファイル | 変更されたファイル（ステージ状況つき） |
| `3` | ローカルブランチ | ブランチ一覧（`[` `]` でリモート / タグへ切替） |
| `4` | コミット | **コミットグラフ**（`[` `]` でリフログへ切替） |
| `5` | スタッシュ | 退避した変更 |

### パネルの移動

| キー | 動作 |
|------|------|
| `h` / `l`（または `←` `→` `Tab`） | 隣のパネルへ |
| `[` / `]` | 同じパネル内のタブ切替（例: ローカルブランチ ↔ リモート ↔ タグ） |
| `j` / `k` | 項目の上下移動 |
| `Enter` | 選択項目を掘り下げる（コミット → 変更ファイル一覧） |
| `/` | パネル内を検索 |
| `R` | 表示を更新 |

## 3. コミットグラフの読み方

コミットパネル（`4`）を `+` で拡大すると読みやすくなる。

```
f446774d 9:27PM yoshihiko  ◎─╮ (HEAD -> main) feature をマージ
a195aa6e 9:27PM yoshihiko  │ ○ (feature) 機能A
7033edd5 9:27PM yoshihiko  ○ │ main側の作業
b186cb2d 9:27PM yoshihiko  ○─╯ 初期コミット
```

左から **ハッシュ / 日時 / 作者 / グラフ / コミットメッセージ**。

### 記号の意味

| 記号 | 意味 |
|------|------|
| `○` | コミット 1 個。**その行の列の位置**がどのブランチ上かを表す |
| `◎` | マージコミット（親が 2 つある = ここで合流した） |
| `│` | そのブランチが上下に続いている（この行では何も起きていない） |
| `─╮` | ここから枝が右へ分かれる（下に向かって新しい列ができる） |
| `─╯` | 右の枝がここで左の列に合流する |
| `(HEAD -> main, origin/main)` | そのコミットを指しているブランチ・タグ名。`HEAD ->` が今いる場所 |

### 読むときのコツ

- **上が新しく、下が古い。** 時系列は下から上。
- 一番左の列が本流（`main`）。右の列ほど後から分かれた枝。
- 上の例を**下から**読むと:
  1. `b186cb2d 初期コミット` の `─╯` … ここから枝（`feature`）が分かれた
  2. `7033edd5` は左の列 = `main` 側の作業、`a195aa6e` は右の列 = `feature` 側の作業
  3. `f446774d` の `◎─╮` … 2 本が合流してマージコミットになった
- つまり「`│`（縦線）が 2 本並んでいる区間 = ブランチが並行していた期間」。

### 枝が見えないときは

- **デフォルトは現在のブランチだけ表示**。他のブランチも出したいときは
  コミットパネルで `Ctrl+L` →「Gitグラフ全体の表示切り替え」を `Enter`（`git log --all` 相当）。
- このリポジトリは GitHub の **squash merge** 運用なので、マージ後の履歴は
  ほぼ 1 本の直線になる。枝が見えないのは正常。

## 4. パネル別・最低限の操作

### ファイル（`2`） — コミットするまで

| キー | 動作 |
|------|------|
| `Space` | ステージ / アンステージを切替 |
| `a` | 全ファイルをステージ / 解除 |
| `Enter` | ファイルを開いて**行単位・hunk 単位**でステージ |
| `c` | コミット（メッセージ入力） |
| `C` | エディタを開いてコミット |
| `A` | 直前のコミットに追加（amend） |
| `d` | 変更を破棄（取り消し不可、確認あり） |
| `D` | リセットのオプションを表示 |
| `s` | 全変更をスタッシュ（一時退避） |
| `i` | `.gitignore` に追加 |
| `` ` `` | ツリー表示 ↔ フラット表示を切替 |
| `Ctrl+G` | **このリポジトリ独自**: Antigravity でコミットメッセージを自動生成 |

### ローカルブランチ（`3`）

| キー | 動作 |
|------|------|
| `Space` | そのブランチにチェックアウト |
| `n` | 新しいブランチを作成 |
| `c` | ブランチ名を指定してチェックアウト |
| `-` | 直前にいたブランチへ戻る |
| `M` | そのブランチを現在のブランチにマージ |
| `r` | そのブランチの上にリベース |
| `R` | ブランチ名を変更 |
| `d` | ブランチを削除 |
| `u` | 上流（upstream）ブランチを設定 |
| `o` | ブラウザで Pull Request を作成 |

### コミット（`4`）

| キー | 動作 |
|------|------|
| `Enter` | そのコミットの変更ファイル一覧 → さらに `Enter` で差分 |
| `Space` | そのコミットをチェックアウト（detached HEAD になる） |
| `y` | ハッシュ・URL などをクリップボードへコピー |
| `o` | ブラウザでそのコミットを開く |
| `t` | そのコミットを打ち消すコミットを作る（revert・安全） |
| `n` | そのコミットから新しいブランチを作る |
| `g` | そこまでリセット（soft / mixed / hard を選択） |
| `Ctrl+L` | ログ表示オプション（全ブランチ表示・並び順） |

履歴の書き換え（慣れてから）: `r` メッセージ変更 / `s` 下のコミットに squash /
`f` 下のコミットに fixup / `d` 削除 / `i` 対話的リベース /
`C` cherry-pick 用にコピー → `V` で貼り付け。

### スタッシュ（`5`）

| キー | 動作 |
|------|------|
| `Space` | 適用（スタッシュは残る） |
| `g` | 取り出して適用（スタッシュは消える） |
| `d` | 破棄 |
| `r` | 名前を変更 |

## 5. リモートとのやりとり（どのパネルでも）

| キー | 動作 |
|------|------|
| `p` | pull |
| `P` | push |
| `f` | fetch |
| `z` | 直前の操作を取り消す（undo） |
| `Z` | やり直す（redo） |

## 6. 差分の見方

| キー | 動作 |
|------|------|
| `Ctrl+U` / `Ctrl+D`（`K` / `J`） | 右側の差分パネルをスクロール |
| `Ctrl+W` | 空白の差分を無視するか切替 |
| `{` / `}` | 差分の前後表示行数を減らす / 増やす |
| `W` | 2 点間の差分を取るモード（diff menu） |
| `v` | 範囲選択モード（`Shift+↑` `Shift+↓` で複数行・複数コミット選択） |

## 補足

- **翻訳されていない箇所がある**: 新しめの機能（`Copy abbreviated commit hash`、
  `Set fixup message`、`Open pull request in browser` など）と画面下部の
  「ランダムなヒント」は英語のまま。消したい場合は `config.yml` に
  `gui.showRandomTip: false` を追加する。
- 設定の実体は `config/lazygit/config.yml`（`~/.config/lazygit/config.yml` はここへのシンボリックリンク）。
  編集したら lazygit を再起動するだけで反映される（`hxs` 不要）。
- macOS の lazygit は既定で `~/Library/Application Support/lazygit` を見るため、
  `shell/zsh/functions.zsh` の `lazygit()` が `XDG_CONFIG_HOME=$HOME/.config` を渡している。
  この関数を通らない起動（別シェル・スクリプト経由）では設定が効かないので注意。
- 全デフォルトキーの確認: `lazygit --config | sed -n '/^keybinding:/,$p'`
