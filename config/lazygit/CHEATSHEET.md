# lazygit チートシート

`lg` で起動。`↑` / `↓`（`k` / `j`）で項目を選び、`?` で今のパネルのキーを確認。`Esc` で戻り、`q` で終了。

| やりたいこと | キー |
|---|---|
| ファイル・ブランチ・コミット・スタッシュへ移動 | `2` / `3` / `4` / `5` |
| パネル内を検索 | `/` |
| ファイルの差分を見る | `2` → ファイルを選ぶ。右側に表示 |
| ステージ・解除 | `2` → ファイルを選んで `Space`。全ファイルは `a` |
| 行単位でステージ | `2` → ファイルを選んで `Enter` → 行を選んで `Space` |
| コミット | `2` → `c` → メッセージを入力 |
| ブランチを切り替える | `3` →「ローカルブランチ」でブランチを選んで `Space` |
| ブランチを作る | `3` →「ローカルブランチ」で `n` |
| 現在のブランチの履歴・差分を見る | `4` →「コミット」タブ。コミットを選んで `Enter` で変更ファイル一覧 |
| 全ブランチのグラフを見る | `1` → `a`。右側に表示 |
| ローカルブランチの履歴を見る | `3` →「ローカルブランチ」でブランチを選んで `Enter` |
| リモートブランチの履歴を見る | `3` → `[` / `]` で「リモート」へ → `origin` などを選んで `Enter` → ブランチを選んで `Enter` |
| fetch / pull / push | `2` → `f` / `p` / `P` |
| 手元の表示だけ更新する | `1` → `R` |
| 変更を退避・復元する | `2` → `s` で退避。`5` で退避した項目を選んで `Space` で適用 |

リモートの最新履歴を見るときは、先に `2` → `f` で fetch する。
