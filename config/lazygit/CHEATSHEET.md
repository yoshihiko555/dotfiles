# lazygit チートシート

起動は `lg`。**今のパネルで使えるキーは `?`** で確認できる。
標準キーは手元の lazygit 0.66.3 の `lazygit --config` と照合した。ファイルパネルの `Ctrl+G` は dotfiles の独自設定。起動経路と設定先は [lazygit の README](README.md) を参照。

---

## 1. まず覚える 5 つ

| キー | 動作 |
|------|------|
| `?` | 今のパネルのキー一覧を表示（最重要） |
| `Esc` | 一段戻る / メニューを閉じる |
| `q` | lazygit を終了 |
| `1`〜`5` | パネルへ直接ジャンプ |
| `+` | パネルを拡大（もう一度で全画面）、`_` で戻す |

## 2. 画面の構成

左側に 5 つのパネル、右側（`0`）に選択中の項目の内容が出る。

| 番号 | パネル | 何が見えるか |
|------|--------|--------------|
| `1` | ステータス | 現在のリポジトリとブランチ |
| `2` | ファイル | 変更されたファイル（ステージ状況つき） |
| `3` | ローカルブランチ | ブランチ一覧（`[` `]` でリモート / タグへ切替） |
| `4` | コミット | **コミットグラフ**（`[` `]` でリフログへ切替） |
| `5` | スタッシュ | 退避した変更 |

### パネルの移動

| キー | 動作 |
|------|------|
| `h` / `l`（または `←` `→` `Tab`） | 隣のパネルへ |
| `[` / `]` | 同じパネル内のタブ切替（例: ローカルブランチ ↔ リモート ↔ タグ） |
| `j` / `k` | 項目の上下移動 |
| `Enter` | 選択項目を掘り下げる（コミット → 変更ファイル一覧） |
| `/` | パネル内を検索 |
| `R` | 表示を更新（ローカルブランチパネルではブランチ名を変更） |

## 3. コミットグラフの読み方

コミットパネル（`4`）を `+` で拡大すると読みやすくなる。

```
f446774d 9:27PM yoshihiko  ◎─╮ (HEAD -> main) feature をマージ
a195aa6e 9:27PM yoshihiko  │ ○ (feature) 機能A
7033edd5 9:27PM yoshihiko  ○ │ main側の作業
b186cb2d 9:27PM yoshihiko  ○─╯ 初期コミット
```

左から **ハッシュ / 日時 / 作者 / グラフ / コミットメッセージ**。

### 記号の意味

| 記号 | 意味 |
|------|------|
| `○` | コミット 1 個。線をたどると親子関係が分かる |
| `◎─╮` | この例のマージコミット。下に伸びる 2 本の線がそれぞれの親につながる |
| `│` | そのブランチが上下に続いている（この行では何も起きていない） |
| `─╮` | ここから枝が右へ分かれる（下に向かって新しい列ができる） |
| `─╯` | 右の枝がここで左の列に合流する |
| `(HEAD -> main, origin/main)` | そのコミットを指しているブランチ・タグ名。`HEAD ->` が今いる場所 |

### 読むときのコツ

- 既定の表示では子が上、親が下に並ぶ。並行した履歴は前後の行を線でたどる。
- この例では `HEAD -> main` が現在のブランチとその先端を、`feature` がもう一方のブランチの先端を示す。列の左右はグラフの形によって変わる。
- 上の例を**下から**読むと:
  1. `b186cb2d 初期コミット` の `─╯` … ここから枝（`feature`）が分かれた
  2. `7033edd5` は左の列 = `main` 側の作業、`a195aa6e` は右の列 = `feature` 側の作業
  3. `f446774d` の `◎─╮` … 2 本が合流してマージコミットになった
- つまり「`│`（縦線）が 2 本並んでいる区間 = ブランチが並行していた期間」。

### 枝が見えないときは

- 既定では現在のブランチからたどれる履歴を表示する。他のブランチも見るには、コミットパネルで `Ctrl+L` を押し、グラフ全体の表示に切り替える。
- この dotfiles は `main` に直接コミットする運用なので、そこで作業が続いた区間は 1 本の線になる。[リポジトリの Git 方針](../../AGENTS.md#git)

## 4. パネル別・最低限の操作

### ファイル（`2`） — コミットするまで

| キー | 動作 |
|------|------|
| `Space` | ステージ / アンステージを切替 |
| `a` | 全ファイルをステージ / 解除 |
| `Enter` | ファイルを開いて**行単位・hunk 単位**でステージ |
| `c` | コミット（メッセージ入力） |
| `C` | エディタを開いてコミット |
| `A` | 直前のコミットに追加（amend） |
| `d` | 変更を破棄（取り消し不可、確認あり） |
| `D` | リセットのオプションを表示 |
| `s` | 全変更をスタッシュ（一時退避） |
| `i` | `.gitignore` に追加 |
| `` ` `` | ツリー表示 ↔ フラット表示を切替 |
| `Ctrl+G` | ステージ済みの差分から Antigravity でメッセージを作り、エディタで確認してコミット（dotfiles 独自） |

### ローカルブランチ（`3`）

| キー | 動作 |
|------|------|
| `Space` | そのブランチにチェックアウト |
| `n` | 新しいブランチを作成 |
| `c` | ブランチ名を指定してチェックアウト |
| `-` | 直前にいたブランチへ戻る |
| `M` | そのブランチを現在のブランチにマージ |
| `r` | そのブランチの上にリベース |
| `R` | ブランチ名を変更 |
| `d` | ブランチを削除 |
| `u` | 上流（upstream）ブランチを設定 |
| `o` | ブラウザで Pull Request を作成 |

### コミット（`4`）

| キー | 動作 |
|------|------|
| `Enter` | そのコミットの変更ファイル一覧 → さらに `Enter` で差分 |
| `Space` | そのコミットをチェックアウト（detached HEAD になる） |
| `y` | ハッシュ・URL などをクリップボードへコピー |
| `o` | ブラウザでそのコミットを開く |
| `t` | そのコミットを打ち消すコミットを作る（revert） |
| `n` | そのコミットから新しいブランチを作る |
| `g` | そこまでリセット（soft / mixed / hard を選択） |
| `Ctrl+L` | ログ表示オプション（全ブランチ表示・並び順） |

履歴の書き換え（慣れてから）: `r` メッセージ変更 / `s` 下のコミットに squash /
`f` 下のコミットに fixup / `d` 削除 / `i` 対話的リベース /
`C` cherry-pick 用にコピー → `V` で貼り付け。

### スタッシュ（`5`）

| キー | 動作 |
|------|------|
| `Space` | 適用（スタッシュは残る） |
| `g` | 取り出して適用（スタッシュは消える） |
| `d` | 破棄 |
| `r` | 名前を変更 |

## 5. リモート操作と取り消し

| キー | 動作 |
|------|------|
| `p` | pull |
| `P` | push |
| `f` | ファイルパネルで fetch（ローカルブランチパネルでは fast-forward） |
| `z` | 直前の操作を取り消す（undo） |
| `Z` | やり直す（redo） |

## 6. 差分の見方

| キー | 動作 |
|------|------|
| `Ctrl+U` / `Ctrl+D`（`K` / `J`） | 右側の差分パネルをスクロール |
| `Ctrl+W` | 空白の差分を無視するか切替 |
| `{` / `}` | 差分の前後表示行数を減らす / 増やす |
| `\|` | dotfiles で設定した delta の通常表示と横並び表示を切替 |
| `W` | 2 点間の差分を取るモード（diff menu） |
| `v` | 範囲選択モード（`Shift+↑` `Shift+↓` で複数行・複数コミット選択） |

---

標準キーの一覧は `lazygit --config | sed -n '/^keybinding:/,$p'` で確認できる。
