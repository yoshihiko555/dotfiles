# tmux の動作確認手順

WezTerm で tmux を開き、`Prefix+R` で設定を読み直す。Prefix は `Ctrl+Q`。
`Reloaded!` が表示されたら、変更した設定に対応する項目を確認する。
分割や終了の操作には、確認用に作ったウィンドウを使う。

| 対象 | 操作 | 確認する結果 |
|---|---|---|
| ウィンドウと外観 | `Prefix+c` でウィンドウを作り、`Prefix+P` と `Prefix+n` で往復する | 上部中央のウィンドウ一覧で選択表示が移り、右端に baton・セッション名・日時が出る |
| 分割と移動 | `Prefix+r` で左右に分け、`Alt+h/l` で移動する | アクティブな境界線が移り、背景の透過が保たれる。Neovim の分割からも同じキーで移動できる |
| ペインモードとリサイズ | `Prefix+p` で入り、`e`、`h` または `l`、`q` の順に押す | 左端の表示が PANE → RESIZE と変わり、境界が動く。`q` で通常操作に戻る |
| コピー | シェルの出力をマウスでドラッグして離し、`q` でコピーモードを抜けて `tmux show-buffer` を実行する | ドラッグ終了時も COPY 表示とスクロール位置が保たれ、バッファに選択文字列が入る |
| スナップショット | 出力のあるペインで `Prefix+z`、続いて `Prefix+V` を押す | ズーム時に保存した出力をポップアップで読める |
| レイアウト | 1ペインの新規ウィンドウで `Prefix+4` を押し、もう一度押す | 初回は 2×2 に分かれ、2回目は1ペインのウィンドウでのみ実行できる旨が表示される |
| セッション | `Prefix+f` でプロジェクトを選び、`Prefix+w` でセッション一覧を開く | 選択先のセッションに切り替わり、一覧にその名前がある。`Prefix+b` で baton 用の `default` に戻れる |
| チートシート | `Prefix+.` で tmux の「基本操作」を選択する | プレビューにキーと動作の表が表示される |
| WezTerm のキー変換 | `Cmd+t` でウィンドウを作り、`Cmd+d`、`Cmd+Shift+d` の順に押す | tmux 内でウィンドウが増え、ペインが左右、上下に分かれる |

プラグインや個別のキーを変更したときの期待動作は[チートシート](CHEATSHEET.md)を参照。
移行時に実施した項目と未確認だった項目は[移行時の手動確認記録](MIGRATION.md#移行時の手動確認記録)に残している。
