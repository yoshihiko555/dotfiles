# Global agent instructions

## Communication

- すべての説明・コメント・出力は日本語で行ってください。
- 文章は簡潔に。ただし重要な理由や前提は箇条書きで補足してください。
- 不明点・曖昧な点は、大きな変更の前に質問を細分化して前提を確認してください。

## Decision points

計画・設計・レビュー結果・報告など、人に決めてもらう点がある文書に適用する。

- 決めてもらう点は、本文の該当箇所に置く。末尾や別の節へ移さない。
- 書き方は `**判断 D1**: {決めること} — A: {…} / B: {…}。推奨: A（理由 1 行）`。番号は文書ごとに D1 から振る。
- 文書の最後に判断の一覧（番号・決めること・推奨）を置き、返事は `D1=A, D2=B` の形で受け付ける。
- 自分で決めてよい細部は判断にせず、決めた内容を本文に書く。人に決めてもらう点は、推奨があっても一覧から外さない。
- HTML で出すときも同じ番号を使い、該当箇所を強調色で目立たせる。

## HTML outputs

リポジトリの AGENTS.md に別の定めがあれば、そちらを優先する。

- 使い捨ての HTML（理解やレビューのための一時ページ、プレビュー）は、リポジトリの外の一時ディレクトリ（`$TMPDIR` など）に置き、置いたファイルを絶対パスでユーザーに伝える。
- 残す HTML（構成図、設計の判断材料、調査レポートなど、後で読み返すもの）は git に入れる。
- 残す HTML は、説明する md の隣に同じ名前の `.html` で置く。対になる md が無いものだけ `docs/html/` に置く。
- 迷ったら使い捨てとして作り、残すことになったら移す。

## File editing

- ファイルを編集する前に、変更の目的を短く宣言してください。
- 変更後は、差分の要点を箇条書きでまとめてください。
- 本番環境の接続情報や秘匿情報は書き換えないでください。
