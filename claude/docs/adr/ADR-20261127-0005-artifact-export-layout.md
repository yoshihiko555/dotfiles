# ADR-20261127-0005: 1 本の Artifact を書き出し先の 1 つのフォルダに置き、公開したファイルをすべて公開パスのまま写す

- ステータス: 採用
- 決定日: 2026-11-27
- 関連: [ADR-20261127-0003](ADR-20261127-0003-artifact-export-sync.md)（前提。写しの作り方と写す範囲）、[ADR-20261127-0004](ADR-20261127-0004-artifact-export-id.md)（フォルダの名前）

## 背景

Artifact は本体のページ 1 枚に加えて、`files` で別の HTML（2 枚目以降のページ）・CSS・画像などを添えて公開でき、本体からは相対パスで参照する。

- 2026-11-27 に、既にあった Artifact のうち型から作ったものを除く 33 本の公開ファイルを、Artifact ツールの一覧（`scope: "files"`）で調べた
  - 4 本が本体以外のファイル（計 36 ファイル）を持っていた
  - そのうち 1 本は、本体以外に HTML のページを 2 枚持っていた
- 2 枚目以降のページの文章は本体に入っていないので、本体だけを写すと homebase で検索できない
- homebase は `.html`・`.htm` のファイルだけを読み、名前が `.` で始まるフォルダは辿らない（homebase の `docs/requirements/functional.md` の FR-059）
- homebase との約束で、書きかけのファイルを取り込ませないため、取り込みの対象にならない名前で書いてから名前を変える（同 FR-059 の備考）

## 選択肢

### A. 本体だけを `<ID>.html` として写す（不採用）

- 2 枚目以降のページの文章が、homebase で検索できない

### B. 本体を `<ID>.html` とし、添えたファイルを `<ID>/` に置く（不採用）

- 本体からの相対パスの参照が、書き出し先では切れる

### C. `<ID>/` に、本体と添えたファイルを公開パスのまま置く（採用）

- クラウドと同じ並びなので、相対パスの参照が書き出し先でも切れない
- 同期と削除を、Artifact 1 本につき 1 つのフォルダで扱える

## 決定

**1 本の Artifact を書き出し先の 1 つのフォルダに置き、公開したファイルをすべて公開パスのまま写す。**

1. 本体のページは `index.html` として置く。クラウドの read でも、本体は `index.html` で取れる
2. 添えたファイルは、HTML 以外（CSS・画像・CSV など）も写す
3. 再公開で外したファイルは消し、Artifact を削除したらフォルダごと消す

## 検証

- 試験用の Artifact に `files` で HTML と CSS を添えて公開したときの入力を hook に流し、本体が `index.html`、添えた 2 つが公開パスのまま写ることを確かめた（2026-11-27、2.1.332）
- 外したファイルを消すこと、外へ出るパスを拒むことは、作った入力を hook に流して確かめた（2026-11-27、2.1.332）
- 既にあった 4 本の添えたファイル 36 個を、公開パスのまま書き出した（2026-11-27）

## 影響

- 書き出し先は、添えた画像の分だけ大きくなる（2026-11-27 に 33 本で 16 MB）
- 既にあった 33 本の `index.html` は read で取ったもので、公開時に付く外枠（doctype・charset など）を含む。hook で写したものはローカルのファイルそのままで、外枠が無い。homebase での表示に差が出るかは未確認
- 別の Artifact からサーバー側で複製したファイルは、手元に元のファイルが無いので hook では写らない。同期で取り直す
- homebase の docs は、次の点でこの決定と食い違う
  - 1 本を 1 つのファイルとして書いている: FR-059 の備考と `docs/project-overview.md`「homebase の外で作るもの」の「書き出すファイルの名前は Artifact の ID にし、再公開では同じファイルを上書きする」、`docs/architecture/architecture.md`「ナレッジ（v4。ADR-20261123-046〜049）」の「ファイル名は Artifact の ID」
  - 相対パスで読むファイルが無いとしている: FR-059 の備考の「今の資料は、相対パスで画像などのファイルを読んでいない」、`docs/project-overview.md`「スコープ（v4）」の「Out of Scope」の「資料が相対パスで読む画像などのファイルの表示（今の資料には無い。2026-11-23 に確かめた）」

## 決定しないこと

- 外枠の有無を揃えるか: homebase での表示に崩れが見つかったら決める
